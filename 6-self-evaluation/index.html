Self-Assessment

I did my internship in the First Cloud AI Journey program of Amazon Web Services Viet Nam Company Limited from 14/09/2026 to 14/12/2026, as an Intern - First Cloud AI Journey.

In the first seven weeks I followed the program’s learning path: IAM, EC2, S3, VPC, CloudWatch and the AWS Study Group labs. In week 10 I did Experience 2 on Windows security on AWS (EC2 Image Builder with STIG, AWS Config, EventBridge, Systems Manager); my first build failed because the instance type was not Free Tier eligible, and I fixed it. Then the team switched the topic to Cost Guard for Windows Labs. My part was the foundation stack, Layer 1 (scheduled stop), the cost estimate, workshop sections 5.1–5.4, and fixes to the proposal and the architecture diagram. At the end I re-tested all three layers end to end, reviewed a teammate’s CostMeter code, cleaned up every resource, and rewrote section 5.8 with a screenshot for each step.

What I did well

  • I took on my tasks and finished them: I did not stop at a successful deploy, but re-tested on AWS and recorded the results with numbers and screenshots.
  • When reviewing a teammate’s code, I checked the running system instead of guessing, and found that the code on AWS differed from the template in the repo.
  • I kept documents safe: I masked the account ID and emails in every screenshot before it went into the repo.

Needs improvement

  • Read team and program announcements carefully. Sometimes I read a message and forgot it, and had to ask again about things the team lead had already posted.
  • Check account limits before starting. My first Image Builder build failed because the instance type was not Free Tier eligible, and Amazon Inspector was not available on the Free plan. I should have read the limits first.
  • Broaden my technical knowledge. I am comfortable with serverless and EC2 but still weak in networking (VPC, routing) and AI/ML services. I want to learn these two areas next.
  • Report more concisely, especially when writing in English.
